# 元件、字段与连接表达

本文件是局部画法的权威规则。功能组合见 [functional-layout.md](functional-layout.md)，写回与验证见 [editing-and-validation.md](editing-and-validation.md)。用户当前明确要求优先；既有惯例不能保留错误电气含义、遮挡或字段跑位。

## 优先使用已有符号

先查标准库和项目已配置库，按真实引脚编号、功能、电气类型、单元与隐藏供电脚匹配。通用符号能准确表达实际器件时复用，并保留实际料号。只有确实缺少合适定义才新增项目本地符号，依据数据手册核对，不改共享库或以修改引脚类型消除 ERC。

复用兼容型号符号时，实例的 Value、Description、Datasheet、封装与关键规格应对应实际器件；不能只改 Value，却保留另一个型号的错误说明。未知信息不编造。检查原生导出的生效属性，避免自定义字段与标准字段冲突。

纯整理保留实装位号、UUID、Value、封装、DNP/BOM 状态及多单元身份；隐藏只改变显示。完整型号至少在一个主单元可见，保留未用单元和供电处理的电气作用。未决型号或参数如实报告，不以风格整理为由猜测替换。

真实端点由库定义与实例变换决定。非默认网格不自动等于坏库；遇到未展开继承、无法解释的引脚变换或库/实例不一致，先核实定义与原生结果，不靠反复挪线试错修复。工具不支持时列为未验证。

### 实际器件、符号与封装的端子对应

新建器件、换料或更换符号/封装时，先依据实际料号及封装版本的数据手册、引脚表或机械图取得完整端子定义，再对照所选符号的引脚和实际 `.kicad_mod` 的焊盘编号、功能。不能只按有效信号脚数、外形或库名相似选择符号；“优先已有库”以完整匹配为前提，不允许为了复用普通符号省掉辅助端子。仅查询已选符号的引脚，不能证明实物端子齐全。

| 实际结构 | 符号选择与处理 |
|---|---|
| 带安装焊脚的连接器 | 核对全部安装焊盘。封装有 `MP` 等编号时，优先选引脚对应的 `Connector_Generic_MountingPin` 或准确型号符号，不能只用同信号脚数的普通连接器；不另放独立安装孔器件代替连接器自身端子 |
| 屏蔽外壳、壳体焊脚 | 按实际壳体端子与焊盘编号选用带对应脚的符号；不因外观看起来用于固定就当成普通机械脚，也不凭名称推断接地方式 |
| 裸露散热焊盘、金属 tab、重复电源/地脚、检测或开关脚 | 按具体封装资料核对功能、内部连接及编号，不能只保留主要信号脚；NC/DNC 也按器件资料处理，不通过删掉符号引脚表示 |
| 塑料定位柱、纯机械 NPTH 定位孔、无电气编号的机械结构 | 不虚造电气引脚；依据机械图和封装确认其性质，不能仅凭“mounting”名称决定加脚或省脚 |

按编号与功能对应，而不是简单比较图形个数：一个端子可对应多个同编号焊盘；不同编号的壳体/安装焊盘即使计划接同一网络，也不能直接省略。`MP`、`SH`、`EP` 等只是可能的编号，实际库和器件也可能使用数字或其他名称；已有符号不匹配时再用经过核对的项目本地符号，不擅自改共享库或封装编号凑匹配。

每个辅助端子都应有依据地接入指定网络、明确不连接，或保留为未决；安装脚、屏蔽脚和散热焊盘均不自动接 GND。在现有选型/引脚记录中简记特殊端子的资料来源、符号脚↔焊盘编号及处理方式即可，不另造全器件审批表。资料不足或封装未确定时标明具体未验证项，可继续不依赖它的绘图，但不能宣称完整匹配。纯排版不重做无关选型；发现既有漏脚时先记录影响，按任务授权修正并验证，不借整理擅自增加电气连接。

## 字段默认与例外

普通可见字段/标签通常 1.27 mm，长 MOS 型号可局部用 1.0 mm。除框内竖电阻值外默认纸面横读。实际方向结合实例变换判断，不能仅看 property 的原始角度。

| 对象 | 默认画法 | 例外与检查 |
|---|---|---|
| 标准 IEC 电阻短值 | Value 居中放入空心矩形、沿长轴读；新建紧凑局部默认隐藏 Reference | 隐藏和内值独立；既有合理显示/调试需要可保留位号 |
| 小电阻、长值、复合规格 | 放不进本体即正常字号外置；水平件位号上/值下，竖件侧面横读 | 既有局部可沿用合理外置惯例；新草稿不以此跳过默认画法 |
| 电容 | 位号和值保留，贴近极板，按整组选择侧别与行位 | 右侧双行不是固定占地；必要耐压等字段一起排 |
| 电感 | 值靠近线圈上/下侧，紧凑功率通路可隐藏位号 | 长型号外置，沿用合理既有显示 |
| IC/MOS/二极管/连接器 | 位号、必要型号/规格靠近所属本体 | 可隐藏冗余连接器通用库名，不隐藏必要型号 |
| 供电/地/flag | 虚拟 Reference 隐藏，flag Value 默认隐藏，电源名/地名正常可见 | 朝向和名称的专用位置见电源规则，不能当普通字段任意换侧 |

框内值是否容纳以原生字形、方向、字号和对齐下的实际边界为准。空心框内部可放字，但字形不得压框边、实心笔画或导线；字符数/锚点只作筛查，短值也可能不合适。移入时同步设置居中 justify，不缩字、不改库尺寸硬塞。隐藏字段仍保留完整原属性。

### 字段参与首次放置与收紧

普通字段可以换侧、错行、上下分置，靠近本体的边作为定位依据：右侧左对齐，左侧右对齐，上下通常居中。首次放置即选择适用摆法；遇到冲突先处理字段，再给必要的局部净空，避免保住默认字段而持续推远器件。

直接写字段时，纸面意图不等于文件里的原始 justify。KiCad 10.0.5 原生导出已核对：正交实例的横读字段使用 `property_angle = symbol_angle % 180`；若 `(symbol_angle in {90, 180}) XOR (mirror == "y")`，文件中的 left/right 要与所需纸面对齐互换，center 不变。字段 at 的位置仍是纸面锚点，无需绕实例再旋转。镜像 x 不翻转横读字段的左右对齐；其他角度/变换不外推。先核对实际字形伸向哪侧，再调整字段，不能把渲染对齐错误误判为器件必须拉开。

利用极板上下、引脚之间和相邻短字段的空白。允许联合包围盒交叠，实际字形与本体/针号/导线不能互压；文字也不能居中夹在两件之间而归属含糊。字段可细调，电气端点保持精确重合，不把两者都吸附到粗电气网格。

并联支路先以真实接入端点对齐母线，允许本体错层。电容组尤其检查字段的侧别和空白行位、首末颗外侧空间；不要机械左右交替，或由一颗长规格决定全排大节距。交替处理字段、横向节距、上下母线与组端余线，不能将横向紧凑换成无用途的纵向空白。正常位号/值/规格保持可见，不靠缩字或删件取得密度。

原生局部按实际字形检查归属和碰撞，重点看长值、旋转/镜像、末颗支路、返回线及 IC 型号。生成入口支持逐实例坐标、角度、对齐、可见性，并合并调用者覆盖与默认值；不能在内部写死 `fields` 后让调用者无法选择变体。修正保留在有效生成入口中，下一次生成不能覆盖回默认字段。首次生成和重复展开的次序见布局细则。

## 本地支持支路

按服务关系组织，不按器件类别分岛。先区分服务一个公共节点的支路，和服务某器件具体引脚/引脚对的支路；两者都不能只按同名网络找空位。输入/输出电容、TVS、泄放等按实际功能靠入口/所属母线，去耦、偏置、钳位和反馈围绕具体服务引脚。共同母线可直接落真实端点，不例行多留一两格引线；不同引脚长度允许本体错层。

这个原则服从真实拓扑：串联元件留在通路，RC/snubber 等复合支路整体就地接入。保险/反接/滤波前后、AGND/PGND、Kelvin 与浮动参考不因排版合并。公共返回可用就近正确地符号，不要求绕整块画大回路线。

| 局部 | 可读构图 |
|---|---|
| 输入/输出并联支路 | 电容、TVS 等贴所属母线，保护侧别与泄放节点正确 |
| MOS 栅源保护/偏置 | 钳位稳压管贴被保护 MOS，在其 G/S 附近形成清楚的局部支路，偏置电阻接回实际参考端；共享 G/S 网络的其他晶体管不取代保护对象 |
| IC 串阻与端口 | 引脚、串阻、标签锚点同轴；两端不同网络，不被同名标签旁路 |
| 复位/分压/滤波 | R、C 与实际信号节点就地短接 |
| 比较器/运放 | 分压/滤波在输入侧，上拉贴输出，反馈形成短局部回路 |
| 晶振 | 晶振及负载支路靠服务引脚，保留完整局部 |
| 驱动/功率 | 栅阻、实际所需浮动供电和去耦完整，桥臂/开关节点/电感主通路连续 |

例如栅源钳位与驱动晶体管恰好跨同一对网络时，把钳位画到驱动晶体管远侧会使其看起来服务后者。先把 MOS 与钳位组成局部，再从该节点引出驱动支路；不要用包围全部驱动器件的大矩形长线表达这一小支路。具体引脚与极性以当前器件定义为准，不把全部稳压管都归为栅保护；实际保护跨 D/S、入口或其他节点时按真实功能组织。

相似原则适用于反馈元件围绕放大/比较核心、bootstrap 围绕浮动供电端、晶振负载围绕振荡引脚。可读性阻碍确实无法通过换侧/朝向/字段解决时，可作清楚的邻近支持组，但应保留明确的服务端点和阅读路径，不能用“都在同一块”解释漂移。用户给定的局部对照见 [calibration.md](calibration.md#已确认的局部组织偏好)。

普通 IC 去耦优先贴供电脚直连；有清楚短接位置时不以两个同名电源符号替代。大芯片供电脚多且分散，逐脚直连会绕远、挡脚或挤乱局部时，允许同芯片、同实际网络的去耦在其附近集中成紧凑母线组，用正确电源网络连接。无需先画不可读的直连稿。它是按引脚分布作出的布局选择，不是型号白名单。

集中组保留全部器件、参数、具体服务归属和网络域，不把每颗单独飞出，也不收成不同芯片共用的全页电容区。滤波隔离后的模拟供电、VBAT、VREF、bootstrap/电荷泵等按实际端点单独处理。多单元 IC 的去耦优先接其电源单元并随所属核心；隐藏供电脚保留库语义，不虚造可见脚。物理设计意图的记录方式见布局细则。

跨核心/跨页可用标签，驱动与功率、分流器与采样 IC 可用成组端口连接；保留极性和各自完整局部。重复构图包含本体、外围、字段和端口，复制后仍逐路核对参数与网络。

## 端点与导线

常用电气网格 1.27 mm，具体以真实库端点为准。导线正交，采用必要的最短清晰路径。

- **真实端点直连优先。** 串联无源件、IC 外围、电源/地、串阻与标签的端点可重合且可读时直接连接。贴端点而非图形边缘，不缩引脚，不生成零长度 wire。分支、转向、针号/字段净空可保留必要短线。
- **不沿引脚折返。** 导线在真实端点结束，不能从可见引脚中段侧接后覆盖引脚折回，或越过端点穿本体、留下假分支尾巴。正常端点接触和 T 节点不属于此类干涉。
- **零长度引脚也保护图形。** 电源/地/PWR_FLAG 的导线接真实锚点，不从另一侧穿箭头、菱形或地线后留尾段。电位器滑臂回接等支路先在图形外汇合，再从汇合点引出地符号；不要把地锚点放在仍向下延伸的回接线上。可换同网节点或接入方向；不因画法错误删掉有电气依据的 flag。
- **非连接交叉清楚。** 放在远离本体、端点、分支点和折角的空白直线段，不形成近似 T 接、擦碰或共线叠行。严重混接感不能靠“没有圆点”或放大才看得清解释，轻微接近不需统一拉大间距。
- **接点和线段不冗余。** 真实分支优先 T 形，节点分段并放单一接点；不相连交叉不补点。清理零长度、重复、部分重叠线及重复接点时保留真实接入关系，随后核对全图网络端点。

图上导线不模拟 PCB 回流路径。无用途的标签长引线可改为端点直贴或邻近短引出；Kelvin 身份不靠画长线表示。局部歧义优先调整支路/汇合点和字段，不把全图拉散。

## 电源与信号角色

电源轨/地使用真实电源符号，不用信号全局标签或箭头文字冒充。按实际功能识别：供电 Vin/Vout 是电源轨，SW、栅极驱动输出、测量/参考信号不因名字含 V 而自动归为电源。缺同名符号时用目标版本支持的可命名电源符号或项目真实电源定义，验证网名及作用域。

供电默认朝上且禁止朝下，地默认朝下且禁止朝上；负电压也遵守供电规则。按旋转/镜像后的实际图形判断，必要时用短折线接上方地脚或下方供电脚。向上箭头名称在正上方沿轴居中并贴近，向下地名在下方；移动符号和名称整体，不单独搬走名称或倒置符号避让。横向实例仍须含义/归属清楚。

连续局部母线通常各一处供电/地标识，不逐支路复制或叠同名全局标签；远处独立核心保留本地标识。PWR_FLAG 只声明有依据的电源驱动，不能按轨名例行添加，也不能与箭头/地符号叠画。

信号全局标签正常使用，按每个实例的产生/接收角色选择，与摆放左右无关：

| 实际行为 | 类型 |
|---|---|
| 单向产生端 / 接收端 | output / input，含模拟输出、PWM、ADC、一源多收 |
| 开漏故障/复位/使能 | 按驱动者/接收者，开漏、上拉或低有效不意味着双向 |
| UART/SPI/调试 | 逐线判断；TX output、RX input、目标 SWCLK input，实际 SWDIO bidirectional |
| 真双向/三态/无方向无源接口 | 对应 bidirectional / tri_state / passive，不机械继承连接器 pin 类型 |
| I2C | SDA 按双向，SCL 按主从与时钟拉伸行为 |

角色不明先核对引脚/资料，保留未决而非默认双向。纠正已有错误类型要有依据，不能为了翻转外框改 shape，也不能整网一键统一。

## 标签与画布内容

标签真实锚点接节点，外框碰线不等于连接；正文朝空白侧横读，不穿 IC、无源件或其他文字。必要旋转端口整组一致且无遮挡。成组对齐锚点，不为文字外沿齐平拉长导线或把标签全推到框边。分流器正负、栅极、故障端口可换侧/错行，但保留真实端点、极性与归属。

纯整理保留网名大小写、低有效记号、后缀与 Value 文本；不改名凑布局。型号/封装/数据手册属性可按用途隐藏，必要规格保留。画布只保留电路、必要字段、网络名、短功能标题与用户有效注释；计算、验证状态、免责声明、未决项放交付说明，不自行添测试标题或审核日期。图框信息沿用用户提供或工程已有内容。
