# 编辑、影响分析与验证

用于写回原理图、复用生成器、恢复长期任务或判断整理前后是否保持电气身份。只读审查可把导出和报告写到临时目录，不修改工程。绘图偏好见 [drawing-conventions.md](drawing-conventions.md)，有限收紧流程见 [functional-layout.md](functional-layout.md)。

## 基线与写回

先确认目标主文件、层级/项目依赖、当前器件与参数、授权改动。保留基线或已有版本控制中的可恢复版本；用户未保存内容与磁盘不一致时，不直接覆盖磁盘后假定编辑状态一致。新建图要有核实过的预期引脚连接，第一次生成的网表不能自证设计正确。

节点级编辑 S-expression，区分根级实例与 lib_symbols 模板，保留未知字段、UUID、实例路径和多单元关系。直接编辑使用能保留这些信息的解析器；不以全文件正则改结构。移动/旋转/镜像时计算实际端点，原点在网格上不等于引脚已接通。

新增器件分配新身份；整理现有器件不重建 UUID。字段显示与内容分开处理。标签/电源表达替换保留真实网名、作用域与隔离关系；纠正 shape 应有供消依据。不得修改引脚类型、堆 flag 或扩大 ERC 豁免来掩盖问题。

合页/层级迁移只在任务要求时进行，保留原完整实例身份到新身份的一对一映射，逐项处理同名局部网和层级接口，防止合网。内置比较器会报告身份变化，**不自动应用迁移映射或接受授权差异**；需要该功能时另做明确映射比较，并核对其覆盖范围，不能把全部 DIFFERENT 忽略。

## 长期任务与生成器

恢复任务、换方案、更新 skill 或生成器后，确认主文件、生成入口/直接编辑方式、当前检查范围与未决项。首次复用 helper 时也检查其默认：所有电阻强塞框内、固定字段占地、预定大框、无条件引线、电源倒置、标签统一双向等。还要检查它是否默认给每级输入/输出贴标签，以及所谓压缩是否只有整组平移；这两种机制不能代替布局细则的完整核心构图。字段覆盖、真实端点和完整子组接口按[首次生成流程](functional-layout.md#首次生成从端点向外安排)处理；以受影响代表局部的原生导出确认修正后再复用，不要求无关 helper 全部重写。

重跑生成器前检查源中的手工修正是否已回灌。后续以源直接编辑为准时明确停用过期生成入口，防止重建覆盖。记录沿用任务已有工作记录即可，不为每阶段增造大量说明文件。

并存方案明确当前交付/候选/旧版，维护工程已有版本入口；不能仅按修改时间推断取代关系，也不能复用旧方案的检查结论。

## 按实际差异选检查

影响分析依据源差异，不依据“我只是移动一点”的描述。视觉 ROI 是定位提示，不能代表电气影响范围。

| 实际变化 | 电气与结构 | 图面 |
|---|---|---|
| 仅字段位置/对齐/可见性、非电气图形 | 逐节点差异确认内容/网络对象未变后，可复用已匹配基线的电气结果；写明复用依据 | 修改区及受影响邻组原生局部 |
| 符号/引脚/导线/接点/标签几何，哪怕小移动 | 全项目网表端点和身份比较、ERC 差异；不以局部框裁切网络检查 | 修改区、路径涉及对象及邻组 |
| 属性、引脚定义、网络语义、层级、库/项目配置 | 全量数据/网表/ERC；解释本次授权变化，依赖改变时重新建立可比上下文 | 相关核心；作用域/功能变化再看全页 |
| 全图再生成、差异未知、工具无法解析 | 按全量检查，未知项保持未验证 | 按本次范围完整查看 |

字段文本更改不是纯显示微调。电气几何变化即使最终网表相等，仍需复查当前图面。全局核心重组还要看阅读链、归属和图幅。稳定版本的独立检查可并发，但不边写文件边验证。

## 可复用的电气与身份验证器

`scripts/schematic_check.py` 依赖 Python 标准库和目标版本 kicad-cli。路径替换为实际位置，输出目录使用新的、尚不存在的路径；before/after 对同一工程路径在修改前后采集。

```powershell
$styleSkillRoot = 'C:\Users\wuji\.agents\skills\kicad-schematic-style'
$nativeCli = 'D:\app\KiCad\10.0\bin\kicad-cli.exe'
$schematicPath = 'C:\task\project\main.kicad_sch'
python -B -X utf8 "$styleSkillRoot\scripts\schematic_check.py" snapshot $schematicPath --output 'C:\task\checks\before' --kicad-cli $nativeCli
# 完成本批修改后再采集 after，不能同时改源和导出。
python -B -X utf8 "$styleSkillRoot\scripts\schematic_check.py" snapshot $schematicPath --output 'C:\task\checks\after' --kicad-cli $nativeCli --pdf
python -B -X utf8 "$styleSkillRoot\scripts\schematic_check.py" compare 'C:\task\checks\before' 'C:\task\checks\after' --output 'C:\task\checks\diff.json'
```

快照新导出原生 XML/ERC，冻结源/依赖和产物哈希，并比较导出前后输入；不读取旧报告后补上当前哈希。`--pdf` 在同一采集中导出并绑定 `preview.pdf`，可供原生图面检查；只读审查直接采集一次带 PDF 的快照即可，不必制造前后对比。自动收集层级页、工程配置、已解析符号库与导出环境；额外依赖用可重复的 `--dependency PATH` 声明。解析不到的依赖、层级循环或不支持的原生格式会进入 coverage_gaps。快照保存后允许现场源继续修改，比较使用冻结内容，不能修改快照内部文件。

比较维度：器件 UUID/完整实例路径/位号/单元、层级、属性与引脚定义、原生导出生效属性、稳定身份加引脚号的网络端点集合、NC/引脚语义、显式标签作用域、ERC 规则及对象身份。忽略网络自动编号；只有源中没有标签、电源符号等命名机制时才归一化可识别的自动网名。其他情况保留原生网名，可能将真正的自动名漂移也报为 DIFFERENT，需要核实；不能因名字长得像自动名而忽略显式名称的端点变化。网络合并/拆分不会因为数量相同而放行。ERC 按规则/严重程度/对象比较，位置与翻译文本不作为稳定身份。

无引脚机械符号保留在身份与属性检查中：只有源库单元/样式已解析且有效、实例也没有引脚，并且原生 XML 显式提供对应的空引脚清单时才接受。普通器件清单缺失、定义不明或意外网络端点仍报缺口，不按位号前缀豁免。修复工具后重新采集证据，旧 `UNVERIFIED` 快照不回填成通过。

| 输出 | 含义 |
|---|---|
| snapshot 的 CAPTURED / 退出 0 | 证据采集成功，尚未证明电路或图面正确 |
| compare 的 PASS / 退出 0 | 所报告维度等价；ERC 遗留问题可非零，不是“ERC 全清” |
| DIFFERENT / 退出 1 | 存在差异；阅读各维度，区分授权变化与意外改变 |
| UNVERIFIED / 退出 2 | 证据不完整、上下文不可比或格式不支持；已有明确差异仍需查看，不忽略 |

报告含 dimensions、coverage_gaps、limitations 和 impact；impact 分类 display_only/electrical_or_identity/unknown，并列变化对象及建议检查范围。它不判断模拟/高速/热设计、不证明原设计正确，也不自动接受重编号、路径迁移或合法电气更改。不同源路径、不同 KiCad/库/ERC 上下文可能不可直接比较，须解决原因或明确限制，不能抹掉差异换 PASS。

## 几何探针与定向复核

```powershell
python -B -X utf8 "$styleSkillRoot\scripts\style_probe.py" $schematicPath --details --output 'C:\task\checks\style.json'
```

报告是 JSON 数组，每个输入文件一项，含源哈希和检查事实/候选。它不递归展开层级；层级页逐页检查，hierarchy_gaps 保留未展开提示。

| 部分 | 自动覆盖 | 未覆盖内容 |
|---|---|---|
| redundancy | 零长度、重复/部分共线重叠导线、重复接点 | 正确接点的完整性、网络语义 |
| wire_pin_overlaps | 正交旋转/mirror x/y 下，当前单元/样式的可见普通引脚线与导线正长度共线覆盖 | 隐藏/装饰型/零长引脚、不支持定义与角度、一般本体穿线 |
| power_orientation | 匹配内嵌标准箭头/三角地形状的实际变换后方向 | 任意自定义图形的方向语义 |
| power_value_placement | 支持的向上箭头与可见横读 Value 的锚点跑位 | 实际字形包围盒、居中效果、尖端净空 |
| flag_wire_crossings | 标准 PWR_FLAG 菱形内部的导线穿越候选 | 任意电源/地图形、一般符号碰撞 |
| ground_wire_crossings | 标准三角 GND 在正交旋转/镜像后，导线进入三角内部或穿过/覆盖接地短干线；正常止于真实锚点不报 | 自定义地形状、GND 文字字形碰撞、一般符号碰撞 |
| 常规统计 | 外露虚拟位号、同原点电源、非正交线、已知纸张上的器件原点越界、字段/线长等 | 完整内容边界、真实图框/标题栏、紧凑度 |

skipped_objects 按实际未覆盖对象列出原因和身份，not_applicable 区分已知不适用的规则，例如地符号不适用向上电源箭头名称规则。几何候选带 roi_mm、repair_hint；缺可靠位置时 ROI 为空。提示用于找到相关引脚、支路和邻件，不能直接按坐标删线、清空区域或重建器件。工具不确定时先核对库定义/变换与原生局部；非标准库端点本身不构成错误。

候选与未覆盖对象均按适用规则复核。零候选不表示这些对象已通过，脚本没有整体风格评分，也不判定普通字形碰撞、功能归属或局部密度。

## 原生图面与证据

原生指目标 KiCad 实际导出的 SVG/PDF或其可靠栅格化图。必须实际打开对应图面；坐标推演、自绘近似图或只生成文件都不算观察。新建/整体重排先看全页，再查看每个核心及支持组的可读局部；局部修改查修改区与邻组。覆盖长值、旋转/镜像、电源/flag、返回线、密集转角、重复变体及边界。

图面复核分为功能阅读与几何检查：前者按布局细则，从整图独立追踪实际主链和返回关系；后者检查实际字形、符号笔画、连接去向和字段归属。交给复核者当前整图、功能目标及可放大的源/PDF；只提供字段裁图得到的结论，范围就是字段检查，不能升级为构图合格。完整内容应在实际内图框/标题栏允许区内；导出可能裁掉页外内容，还要核对源对象范围。修正后导出当前版本复看缺陷处，不能把旧预览当新证据。

预览优先使用 `snapshot --pdf` 绑定的文件；另行导出的 SVG/PDF 要记录导出前后源/依赖哈希及产物哈希，已有快照不会自动替另一个时间生成的预览背书。人工结论只写实际查看范围和未决项，不由脚本固定字符串代填；快照有 PDF 不代表已经查看。检查结果分别报告电气、图面、紧凑度，未执行项保持未验证。

### 独立复核的输入隔离

新建/整体重排使用[预配置检查入口](review-gate.md)，由未参与绘制的 agent 复核。脚本固定准备证据与派发内容；默认启动全新的只读 CLI 进程，也可按 `dispatch.json` 调用 `spawn_agent(..., fork_turns="none")`。不复用参与设计、修图或已读作者结论的 agent，无需另开用户聊天；独立执行器不可用时保留未验证。普通局部改动按影响范围复核，不为每次挪字段重新开人。

独立性同时取决于输入，按以下顺序执行：

1. **给原始材料和规则。** 派发仅含原始功能目标、用户有效绘图要求、当前源与必要依赖、匹配的全页原生导出及哈希、适用规则和只读范围。预配置入口复制绘图与布局细则，固定提示词承接本节的观察和证据要求；第一遍不读 `calibration.md`、历史图集、本项目既往报告、聊天评价或作者总结。已确认的绘图偏好从规范读取，不夹带本图“已合格/还很松”的结论。材料置于独立目录，排除无关报告；共用文件系统仍不是权限隔离，不能宣称完全隔绝信息。
2. **先形成独立观察。** 复核者从整图自行追读主链、返回与支持归属，再看局部；在收到作者解释或定向缺陷清单前，先提交带位号/节点、位置、原生观察依据及未覆盖范围的首轮意见，分别判断功能阅读、几何与紧凑度。作者的归属表是待核对声明，不能代替追图。允许没有发现问题，不设找错数量，也不暗示应通过或应驳回。
3. **再对照与复查。** 独立观察形成后才对照旧问题和自动报告，核实差异。复核者只提问题及必要改向，主 agent 修改，再触发[检查与修复闭环](review-gate.md#检查与修复闭环)。默认每轮用新上下文，先检查当前图面，再读取入口冻结的上一轮审查者报告，逐项回报处理结果及新问题；不传作者的修复自评。临时沿用同一复核者追查某个问题时，如实称修复复核，不冒称新的独立首审，也不以其代替入口要求的独立结果。

派发和回报放在任务已有记录中，保留受审版本、首轮原始发现与处理结果；有争议时依据实际图面和源核实，不靠投票或把复核意见改写为通过。若首轮前已经读到本图历史结论，披露其范围，不称盲审。全新上下文只减少历史解释的影响，不保证判断正确；本节不替代电气验证和布局细则的有限停止条件。

## 序列化器的条件验证

新建/改写序列化器、格式迁移、目标 KiCad 版本变化，或已经出现原生保存差异时，在隔离工程副本进行一次原生打开、保存、重开与网表/身份比较，副本保留完整依赖。CLI 能读取不等于编辑器保存稳定。已验证链路上的普通局部修改无需每次重复；无法执行则明确未验证。不得盲改文件版本号。

## 工具回归

脚本变化后运行包内测试；目标版本升级后补跑实际原生导出。测试保护可判断的身份、网络、几何与证据不变量，不代表模型审美稳定性。

```powershell
$env:KICAD_CLI = $nativeCli
python -B -X utf8 -m unittest discover -s "$styleSkillRoot\tests" -v
```

未设置 KICAD_CLI 时，依赖原生导出的测试会明确跳过；本包当前实际验证版本为 KiCad 10.0.5。审美尺度用 [calibration.md](calibration.md) 的可重复局部候选；未获得用户认可前不称为标准答案。规则更新的效果需要后续真实绘图对照，不能仅由测试数量推出成功率。
