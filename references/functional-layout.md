# 功能组织、有限收紧与图幅

用于新建多核心、整体重排或审查松散布局。符号/字段/局部连接的画法以 [drawing-conventions.md](drawing-conventions.md) 为准，本文件只规定组织和验收过程。

## 功能归属先于坐标

按能量/信号流划分功能块，一个块可含多个核心，例如栅极驱动和功率主拓扑。核心是能独立读懂的主器件及局部回路；支持组是为某核心或特定节点服务的去耦、保护、参考、滤波、电源单元等。核心边界按功能成立所需的电路确定，不按单个晶体管、每一级或生成函数划分。例如差分对、负载及相邻驱动可共同构成误差放大核心；阈值网络、判定器件与迟滞反馈共同构成温控判定核心。标题和外框不创造这种完整性。

先保留最小信息：核心成员，关键支持组的作用及具体服务的器件/引脚，检测到执行的阅读链，需一起安排的组合。只写“属于驱动模块”不足以决定某颗保护件的位置。简单任务在工作记录中用一行“器件/支路 → 服务对象及端点 → 作用 → 局部或跨核心接口”表达；复杂任务用 [layout-contract.md](layout-contract.md) 的小型映射，避免合并后重新猜测。映射不冻结坐标、宽高或外框。

| 关系 | 放置依据 |
|---|---|
| 主通路/控制链 | 默认顺着阅读方向连续，允许清楚的上下层；避免跨全页往返 |
| 核心与支持组 | 先贴具体受保护/被驱动/被采样的器件及端点，再合成功能块；共享两个网络不意味着可随意交换支路位置 |
| 跨核心接口 | 核对真实端口、极性和供消角色，直连或成组标签按可读性选择 |
| 空白利用 | 在不打散上述关系的前提下互补凹空、错层排列；不按器件类别塞空隙 |

### 构图顺序：局部电路先于跨组连线

1. **选骨架与服务锚点。** 确定功率主通路或信号处理链，安排主器件及朝向。先让相邻级的实际输出与输入接得顺，再附着外围；朝向服务于真实引脚关系和阅读方向，不先把所有器件摊成行列。闭环电路同时安排取样返回，迟滞或局部反馈同时安排其返回端。
2. **就地构造紧凑局部。** 保护、偏置、反馈、滤波与浮动供电按作用附着到具体引脚/节点；放下一颗时一起决定字段、支路接点和必要净空。按下一节从近处生成，不先用宽松坐标接通全部器件。局部范式见绘图细则。
3. **安排接口再组合。** 完整局部之间决定直连还是标签。相邻级可短接时保留连续主链，不先截成带输入/输出标签的小岛再决定摆放。跨核心控制/状态/使能扇出，若共用一条长线会把消费者拖到同一行或形成大外框，优先在各核心就地用同名、角色正确的信号标签。电源轨仍用电源符号。确需切断主链或反馈时，使收发两端、方向和对应核心清楚，并在已有工作记录中简述切断原因。本地与全局标签均按相同功能边界判断，作用域正确不等于构图合格。
4. **核对后集成。** 绘制者查看当前原生局部，按有限流程处理已发现的余量后交接。已有草稿若骨架错误，先局部重新构图，而不是固定所有连线路径后把坐标向中心缩放。生成器的放置入口和并发片段也按完整局部组织，不能先拉完跨组长线再交给各负责人挤空间。

共享网络的电气分支顺序通常不影响网表，绘图时可以调整接出位置表达主次；有明确连接侧别、Kelvin 或滤波前后要求时保留实际拓扑。关键支路的视觉归属优先于统一对齐、少放一个标签或矩形包围盒更小。不让通用网表布局、导线总长最短、无交叉或包围盒面积成为唯一构图目标。

### 首次生成：从端点向外安排

这是一种构造方法，适用于主 agent 和局部绘制者，不另设逐模块的独立审批。目标是首轮形成可读的紧凑局部，避免让全图 review 充当反复缩短默认引线的排版器。

- **坐标从接入关系推导。** 先选真实服务端点和器件朝向，再算实例原点。串联件、标签和电源可直贴时，额外引线从零开始；有分支、针号、字形或转弯需求才留对应空间。并联件先确定接入母线及返回方式，再按实际本体和已选字段的净空定邻距；隐藏位号/框内值后的支路不沿用外置字段的宽节距，也不能按预定行高把母线推远。非连接端点和线段仍保留清楚净空，不盲目把所有端点重合。
- **字段与器件一起求位置。** 在首轮就选右/左、上下或错层等适用排法；先消除默认字段造成的占地，再扩展局部间距。只处理当前冲突，不让一个长型号决定整排节距。相关支持件贴所属引脚，互不相关的核心保留可辨边界；缩短阅读路径优先于把所有图形挤成一团。
- **重复之前确认代表局部。** 多路 RC、去耦、驱动或接口先完成一个完整局部；并联阵列先查看相邻两支及端部。独立通道先把该路串联、偏置和保护组成可跟读的链，再展开其他路，不先按器件类别分成几排同名标签小岛；引脚密集确需分组时保留逐路对应。用实际库、正常字号和本任务最长/旋转等代表字段原生导出自看，确定构图和字段策略后再复制。复用只涵盖已确认的引脚几何和字段条件；复制后核对每路网络、参数及差异。几个代表可同次导出，不逐器件开审查。
- **第一次原生图就是工作依据。** 完成局部后沿输入/主器件/输出及反馈读一遍，并看其内部空跨度。常规问题由绘制者在交接前按有限流程批量处理，直接修生成入口或当前源；不把“先接通，后面 reviewer 再压”作为交付方式。无法解决的阻碍如实交接，不伪造自查通过。

新建时使用 [sch_author.py 绘图工具](authoring-tools.md) 已覆盖的引脚依附、字段变体、母线和组操作，避免重新实现变换与序列化。已有可靠生成器继续使用，补足真实引脚定位、逐实例字段覆盖、完整局部成员与可调整间距/朝向；直接编辑也按同一关系，不为此强制转换旧工程。例如目标端点为 `t`、待放器件该引脚变换后相对原点的偏移为 `p`，直连时实例原点取 `t - p`；需要空隙时才加入有用途的偏移。工具实现坐标关系，构图与原生字形判断仍由作者负责。

局部原点落在主器件或稳定电气节点，标题与外框在内容确定后放。相关成员用引用/句柄显式组成组；整组变换同步更新源对象和 helper 缓存的引脚/端口。避免先以标题定位大块、再靠 `x/y` 阈值挑器件补丁式移动；需要改形就改明确的支路或子组。修正同一默认造成的多处问题时，回改字段/接入/节距策略并重生受影响实例，不逐处叠加坐标补丁。

### 保留电气与物理设计意图

同网并不等于同一个服务对象。已有的具体供电脚归属、滤波前后域、Kelvin 取样、bootstrap/浮动参考、敏感参考与器件放置要求，要随支持组保留在现有属性或归属记录中；无需为此往画布添加解释段落。不了解的物理约束保留为未核实，不自行发明。

图上距离不等于 PCB 回路面积。允许同芯片同实际网络的集中去耦组，但它不撤销电容对具体供电脚或域的服务关系，也不意味着 PCB 可以集中摆在远处。高速身份本身不是禁止图面归组的条件；不能因图面归组而合并实际节点、混用参考域或删除已有物理约束。后续 PCB 工作仍依据实际布局要求。

## 局部与全局分开收紧

局部负责人处理真实端点、器件节距、字段空位、短线、组端余线及完整支持回路。主 agent 负责核心之间的邻接、形状互补、阅读顺序与整页位置。两层都检查，不能用各子模块的宽高缩减替代全局组合。

不把本体、引脚、字段的联合矩形当作不可进入的实心块：可利用实际空白，允许包围盒交叠，但实际笔画、连接和归属要清楚。反过来，也不为追求最小面积把字形挤到相切。没有跨工程通用的间距、密度百分比或最短导线阈值。

收紧检查针对具体空跨度，而非整块外框变小。逐核心检查以下适用类别，主 agent 再检查最后一行；在已有工作记录中只记实际发现的候选、处理结果或保留理由，不另造逐器件打分表。

| 检查对象 | 可收余量与处理方向 |
|---|---|
| 相邻级、上下器件的真实端点 | 直线中段没有支路、字段或阅读用途时，缩短跨度；可直接接端点，或按真实引脚改向、错层。左右对称、等间距行列本身不构成保留长空线的理由 |
| 反馈、偏置、保护及返回支路 | 检查宽大回线和远置汇合点；先靠服务端点重排局部，避免用包住大片空白的矩形表示短回路 |
| 并联支路与母线 | 检查支路节距、上下母线高度和首末接点外余线；让真实端点接入，不只缩横向而留下纵向空线 |
| 字段与内部空洞 | 按绘图细则换侧、错行、校正实际对齐；用本体与字形之间的真实空白安排相关器件，不把默认字段区域或整组包围盒当禁区 |
| 核心间邻接与整图 | 收回块间空档，互补凹空，缩短无功能用途的跨组牵制；需要时回改局部形状，不只整块平移，也不把无关器件硬塞进空洞 |

线长或空白本身不是错误证据：保留处应能指向具体的引脚/字形净空、分支接入、服务关系或阅读需要。判断基于正常尺度下的当前原生图面；“已经比之前紧”“整齐”“以后可能加东西”不能单独证明本次余量有用。

### 全局组合：收拢内容，不铺满纸张

以主核心和阅读链为位置基准，逐个把完整局部接到最近的合理空位，再放短标题和贴合内容的框。标签接口允许自由移动完整局部，不需要为了和另一组的标题、顶边或行基线对齐而拉开距离。去耦、保护、采样等仍保留具体服务对象，不能为了填空把它们打散。

先找**把内容撑开的内部空白**：两列之间贯穿多组的空带、上下行之间的空带、长细核心旁能容纳相关小组的凹口，以及只被标题/层级框/安装孔符号撑开的范围。分别检查向邻组靠拢、上下错层、交换小组位置是否可行；挑对实际阻碍有用的改法，不枚举排列。对高大 MCU，先利用其左右侧在不同高度的实际空位，避免让旁边所有小组继承 MCU 的整列高度；多个小组不必同高、同宽或同一标题基线。层级入口和无电气引脚的机械声明按内容紧凑摆放，原理图上的安装孔间距不表达 PCB 孔距。

一行的最低端若只由某一局部支路决定，下一组可利用其侧边空位，无需等整行结束才开始；有依赖的主链和支持关系仍优先。遇到因长值、标题或单个尾部支路造成的宽大包围盒，先调整该处形状，再组合。若生成器预先分配了固定行列槽位，应改槽位和组形，单独缩两条导线不能解除整页占位。

收紧后留在内容外缘的剩余纸面不必填满，标题栏保留区也不是可利用空白。区分这种正常留白与内容内部可消除的空带；不设满版率或统一密度门槛。组内短线、组间邻接、纸张适配是三个独立问题：局部都紧不代表组合紧，较小纸张失败也不解释当前排列中的空带。

## 有限的默认验收流程

下面是一轮有覆盖范围的检查，不是证明全局最优的搜索。新建/整体整理覆盖各核心和整图；局部任务只处理修改区与受影响邻组，只读审查只报告候选，不擅自试改。

1. **绘制者完成局部构图。** 按上述顺序完成每个核心；沿原生局部跟读主链，再找取样/反馈返回和关键支持支路。将实际位号或节点组成的阅读链简记在已有工作记录中，并标出跨核心标签接口；若只能反复查找内部网名才能拼出同一核心，先调整核心边界和构图。再按“作用 → 服务端点 → 画面位置”反查支持归属，完成字段、间距和变体检查。
2. **交接前覆盖局部余量。** 绘制者按上表前四类查看各核心，把同一结构原因造成的多处空跨度合并处理。先完成一轮批量调整；受阻的候选再做一次针对该阻碍的字段换位、错层、较小移动或改向。不是每核只选一处、成功挪动一次就结束，也不按所有器件、方向和步长穷举。失败只说明该改法失败；保留当前布局时记录具体阻碍，尚未解决的余量仍是待处理项。此步骤就是首次绘制自查，不在全图集成后无故从头重做；集成改形或修复影响的局部另行复看。
3. **全局组合一遍。** 主 agent 按上一节从整页找最大的内部空带与凹口，沿阅读链收回空档；某核心外形妨碍邻接时，给它一次具体回改要求，例如让供电组移到上侧而非直接缩整块。记录实际涉及的核心/位号、移动方向与阻碍，复核归属未漂移。先判断当前内容是否组合紧凑，再按下一节检查图幅。
4. **独立复核当前图面。** 按[输入隔离规则](editing-and-validation.md#独立复核的输入隔离)准备复核者；从功能目标和当前整图独立跟读主链、反馈/迟滞和关断关系，再从主器件反查其保护/反馈、从支持件反查服务对象。随后按上表检查余量，分别给出功能阅读、几何和紧凑度结论；局部放大用于确认端点与字段，不代替全图阅读。每页分别记录组内和组间的具体空间观察；检查入口用 `space_checks` 保存位号/节点、位置、可行处理方向或实际保留约束。覆盖各核心后合并相同原因的候选，不把“一处长线已修”替代全页检查。存在明确问题时，按[检查与修复闭环](review-gate.md#检查与修复闭环)由主 agent 修改、检查 agent 复查；后续批次围绕问题与影响范围处理，不无理由重启全页排列搜索。

紧凑度完成的依据是：适用类别及全图已覆盖，发现的具体余量已处理或有经当前图面核实的保留理由。图幅适配另作结论；其证据缺失不抹掉当前图面已确认的松散，也不把充分检查过的组内/组间结论自动降成未知。没有具体候选的“也许还有更好排列”不阻止结束。有未处理空跨度、仅因尝试次数用完而留下的候选，或未完成的必要检查，分别报告为紧凑度未完成/未验证；可交付已有可用版本并列明剩余项，但不能称整体验收合格。功能割裂、保护归属漂移、连接歧义、字形压线或错误朝向仍按图面缺陷处理，不因完成一轮流程放行。

## 内容稳定后选图幅

用户未限定时不预设 A4、A5、A3 或固定页数。保持正常符号/字号，用收紧后的内容选择纸张。新建图的分页依据功能边界、复用需求和阅读负担，不按子 agent 人数或生成文件数分配页面；小核心可在同页保持清楚边界，不必各占一页。既有图不为提升表面利用率擅自合页或改层级。多功能页可用贴合内容的框和短标题；单个紧凑核心可不加框。沿用既有风格，新的功能框可用 0.2032 mm 深红线、2.286 mm 斜体短标题，不给各块预分等宽大格。

**先审分页，再审每页纸张。** 整体审查先并看全部页面：把核心及支持组当作可以重新组合的内容，不把作者既定页数当作约束。分别核对单独成页是否有复用层级、独立阅读负担或用户指定等依据，以及小页中的完整功能组能否进入主页面的凹空/空带。功能分块本身不需要分页，几个彼此隔开的标题也可以在一页清楚表达。各页都可读、都用了 A5、由不同子 agent 负责，不能单独证明分页合理。

新建图，或任务范围已包含改变分页/层级的整体整理，若出现具体可合页候选，先在工作副本尝试一次减少页数的组合，再针对主要阻碍调整一次局部形状，检查正常符号/字号、归属、阅读链和真实图框/标题栏。记录参与组合的核心和具体成败原因，不预设一页必然放得下，也不穷举最少页数。合页后按新的内容边界选择图幅；迁移作用域和身份按验证细则处理。刚生成的层级结构不是“必须保留的旧工程惯例”。只读审查、既有局部修改或仅整理既有页内版式时，报告候选与依据，保留现有层级；用户明确固定的边界也予以保留。不能把作者刚决定的分页伪装成用户限制。

独立报告的 `pagination` 判断全工程分页，`space_checks` 的 `across_sheets` 记录实际页面/核心及组合机会或保留约束。多页整体审查需要这一层，即使所有页均为 A5；它不能被单页的紧凑度或图幅例外替代。没有看到全工程或候选证据不足时保持未验证，有明确未处理的拆散问题则不通过。

新建/整体整理且用户未限定图幅时，在完成内部收紧后，实际验证一次相邻较小图幅。先用真实内容边界核对该候选的内图框、分区边栏与标题栏保留区；正常尺度下直接容纳时可据此导出复看，否则在工作副本做一次候选组合，并针对主要阻碍做一次局部改形。不能凭“看起来差不多”或“收益有限”跳过。局部修改通常保留原纸张；只读审查不试改工程，只说明较小候选的证据状态。

试排包含全图阅读、字段及边界复核，不只是把 paper 字段改小。候选从同一版已收紧的局部出发，按候选内图框重新组合；解除原大纸的行列位置和标题基线，优先安置真正限制宽高的核心，再用完整小组利用凹空。生成器为候选保留明确的最终组原点/组形；不把候选位移叠加到另一套仍在变化的大纸修补位移上。所有可见对象及源中未被导出显示的页外内容均要核对，PDF 裁掉的内容不能漏算；只落在纸张外边缘以内也不够。

**先判断试排是否充分，再判断保留哪张纸。** 整组平移只测试已有外形能否组合。组内长空线、游离支路、固定字段占地或继承旧行列造成的碰撞，仍是待处理的布局问题。候选出现重叠/越界时，定位主要冲突对象，在上述有限流程内做一次针对性换位、错层或局部改形，并查看更新后的完整候选。没有核对可用凹空、没有处理主要阻碍，或把若干组直接堆到页外的版本，属于试排未完成。罗列这些碰撞不能把它变成较小图幅失败的充分证据。

| 候选状态 | 可作的结论 |
|---|---|
| 内容完整、正常尺度可读且通过真实边界复核 | 采用较小候选 |
| 已完成候选组合和针对主要阻碍的调整，仍有具体引脚/字形净空、服务关系或阅读链约束 | 可保留已验证的较大图幅，记录实际阻碍；不宣称更小图幅绝无解 |
| 仍有未处理的排版碰撞、页外堆放或旧槽位 | 试排未完成，图幅选择尚未成立；独立报告用 `paper: fail` 和具体待办，继续当前有限流程 |
| 没有候选、未实际查看或缺少必要证据 | 独立报告用 `paper: unverified`，补做缺少的检查 |

独立检查以 `space_checks.level: paper_trial` 记录候选对应的核心、布局调整与主要阻碍，区分充分尝试后保留和仍需处理的排法。它与当前页的组内/组间观察分开；不能因较小候选失败而关闭当前图已确认的余量。达到有限停止条件时可交付草稿与剩余项，不将尚未成立的图幅标为最终选定。默认只验证一个相邻较小标准图幅；已到 A5 的常规任务可记该项不适用，用户另有要求时按任务处理。此例外只免除再试更小纸张，各页仍按前述流程检查组内和组间余量。不递归搜索最小纸张，也不为套小纸缩字体、删支持器件或破坏阅读链。

## 并发与端口握手

器件/引脚/接口明确后即可并发，不必等待全部非依赖工作。局部负责人独占片段或生成模块，主 agent 独占主图集成和共享定义；不让多人同时写同一文件。新绘制 helper 先通过本任务代表局部自查再扩散给多路实现；这只延后依赖该画法的批量展开，独立局部继续并发。检查可在稳定版本上并行，输出各自独立路径。

派发局部绘制使用 [local-author-prompt.md](local-author-prompt.md)，填入该文件列出的实际任务输入即可，不只发一句“画完后主 agent 会统一压缩”。这是绘制者提示词，与只读审查者分工不同；不把作者的自评交给独立审查包。主 agent 自己绘制时执行相同首轮流程。

交接局部除成员、关键支路的具体服务端点和不可拆散关系外，还应包含：局部原点、实际连接端口的锚点/单元/引脚或标签 UUID、相对坐标、出线方向、网格、网络/作用域、极性、供消角色，以及采用直接连线还是标签。主器件与它的保护/反馈局部交给同一负责人。小任务用简表，机器检查用归属记录。直接相接双方先协商端口高度和可调整边；标签接口无需强行共线。

网格从真实库引脚导出，常用 1.27 mm；合法的其他网格如实记录，不为了统一网格改库或移动端点。出线方向是可协商的几何意图，不是永远冻结的端口槽位。主 agent 看全图后可要求局部改形，合并后核实真实锚点、接线、字段和邻接，再做全图电气差异检查。

局部交接按固定提示词报告状态及本表前四类空间观察，并附当前原生预览/源版本、阅读链、端口与可调整边。只看了字段碰撞不等于已覆盖紧凑度；主 agent 按实际剩余项识别未完成局部。预览可来自整页中的该局部，不要求逐模块创建工程或重跑完整独立 gate。内部默认长线、重复节距及字段冲突由局部负责人完成；主 agent 接管全局组合及它引发的局部改形。未完成局部可用于临时接口验证，但保持待办，不冻结其宽高。

主 agent 同步推进自己的工作，收到可用局部就集成，不空等所有子任务。检查时区分局部真实占地与标题占地，并确认服务归属和阅读链后再拼合。分工开销大于收益的小修改直接完成。
